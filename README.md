# Automated-intrusion-detection-and-alert-system-with-IoT-integrated-and-AI
This project is a smart security system that uses AI and IoT to detect intrusions and alert users instantly via SMS. It also features a voice-enabled AI assistant that lets users interact with the system and even open the application just by speaking.
